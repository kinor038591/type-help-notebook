# TYPE HELP // 調查員終端筆記系統 (type-help-notebook)

> A web-based investigation notebook & command tracker for the puzzle game "Type Help" | 《Type Help》文字解謎輔助筆記工具（支援指令解析、代號字典與矩陣全覽）

🔗 **線上使用 (GitHub Pages)**：`https://<你的GitHub帳號>.github.io/type-help-notebook/`

---

## ✨ 功能特色 (Features)

專為文字指令解謎遊戲《Type Help》打造的純前端輔助筆記系統，無須安裝或註冊，所有資料皆即時儲存於瀏覽器本地端（`localStorage`），適合與遊戲視窗並排遊玩。

* **🔍 指令結構自動解析**：輸入如 `01-QU-1-11` 或批次貼上遊戲內的 `list` 輸出，系統會自動拆解為「序號 (`01`)」、「文檔類型 (`QU`)」與「尾數參數 (`1`, `11`)」，並区分系統指令與未知待破譯指令（含 `?`）。
* **📖 代號與命名規則推測字典**：
  * 自動掃描並統計目前已發現的所有「序號、類型、尾數代號」出現過的文檔。
  * 支援**全域字典推測**與**單篇特定位置專屬註解**（解決同一指令出現重複數字如 `1-1` 的推理需求）。
* **📊 全局二維矩陣與交叉比對表**：
  * **序號 × 類型矩陣**：鳥瞰所有檔案進度，點擊空白格 `+` 可快速建立待測指令。
  * **文檔 × 尾數參數交叉表**：一覽各號碼在不同文檔中的出現分佈，協助推敲 `?????` 未知指令。
* **🕸️ 線索關聯追蹤與自動掃描**：記錄每個指令的發現來源與衍生指令，支援從遊戲原文與筆記中一鍵掃描並建立新指令關聯。
* **🧪 未知指令破譯測試板 (Scratchpad)**：針對帶有 `?????` 的未知指令，快速組合已發現的參數代號、一鍵複製到遊戲測試，並標記有效或無效避免重複嘗試。
* **🖥️ 半螢幕並排最佳化與全螢幕閱讀器**：
  * 支援左右欄寬自由拖曳調整、左側清單一鍵收合。
  * 內建 4 段獨立內容字體縮放（`A-` / `標準` / `A+` / `特大`），放大內文時不擠壓介面按鈕。
  * 提供「**並排大視窗**」模式，可全畫面左看遊戲原文、右寫推理筆記。
* **💾 多重備份機制**：除瀏覽器即時自動存檔外，支援 `.json` 完整備份匯出／匯入，以及匯出 `.md` (Markdown) 調查報告。
